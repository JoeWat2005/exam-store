# indexes

Reverse lookups. When you don't know which archetype/family/file fits, start here.

| File | When to use |
|---|---|
| [MASTER-INDEX.md](./MASTER-INDEX.md) | Master directory of everything in the vault, grouped by use case. |
| [IF-YOU-SEE-X.md](./IF-YOU-SEE-X.md) | 220+ trigger phrases from exam-question wording → archetype + file. **In-exam workhorse.** |
| [KEYWORD-INDEX.md](./KEYWORD-INDEX.md) | 500+ keyword → file mappings — broader than IF-YOU-SEE-X. |
| [TYPE-SIGNATURE-DATABASE.md](./TYPE-SIGNATURE-DATABASE.md) | Reverse lookup from type signature pattern → archetype + family + canonical file. Used when only the sig is given. |
| [TYPES-REFERENCE.md](./TYPES-REFERENCE.md) | **Single-page reference for every `Types.hs` ADT** used in Mock + assignments — `Rose`, `NimGame`, `Expr`, `Circuit`, `BT`, `Grid`, Morse types, `Free`. Saves hunting through archetype pages. |
| [MOCK-Q-INDEX.md](./MOCK-Q-INDEX.md) | Mock Q1–Q5 verbatim spec + canonical solution + marker quirks. |
| [PROBLEM-NUMBER-INDEX.md](./PROBLEM-NUMBER-INDEX.md) | 150 practice problems → archetype + file + family. |
| [LECTURE-INDEX.md](./LECTURE-INDEX.md) | Lecture-section → topic → archetype mapping. |
| [PRELUDE-INDEX.md](./PRELUDE-INDEX.md) | 200+ Prelude / `Data.List` / `Data.Char` / `Data.Maybe` functions with signatures, what-it-does, where-used, pitfall. Parsed by `scripts/prelude_lookup.py` — do not change format. |
| [ASSIGNMENT-INDEX.md](./ASSIGNMENT-INDEX.md) | Assignment 1–3 + MockTest → archetype + family + lecture. |
| [BEGINNER-INDEX.md](./BEGINNER-INDEX.md) | Linear cold-start reading path. Use when you're *not* yet comfortable enough to use the lookup indexes directly. |
| [ARCHETYPE-INDEX.md](./ARCHETYPE-INDEX.md) | A01–A24 one-page map: per-archetype template + mutations + crossings + attacks + pitfalls in one hop. |
| [CROSS-TOPIC-INDEX.md](./CROSS-TOPIC-INDEX.md) | Data structure × monad matrix (Tree×State, Expr×Either, …) — the hardest exam shape. |
| [MUTATION-INDEX.md](./MUTATION-INDEX.md) | Every mutation across all 24 families listed on one page. Use when you've matched an archetype and want the variant list. |
