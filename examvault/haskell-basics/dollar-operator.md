# The $ operator

## What this is
`$ :: (a -> b) -> a -> b`, `f $ x = f x`. Right-associative, lowest precedence.

## Mental model
Saves parentheses around the function's final argument. `f $ g x` instead of `f (g x)`. Useful when the argument expression is long.

## Syntax
```haskell
($) :: (a -> b) -> a -> b
f $ x = f x
```

## Small examples
```haskell
>>> putStrLn $ "answer is " ++ show 42
>>> map (*2) $ filter even [1..10]   ==> [4,8,12,16,20]
>>> show $ 1 + 2 + 3                ==> "6"
```

## Exam use
Anywhere you'd write `f (long expression)`. Helps readability in pipelines.

## Common mistakes
- Overuse — `f $ g $ h $ x` is equivalent to `f . g . h $ x` and the latter is clearer.
- Precedence surprises: `a $ b + c` is `a (b + c)`, not `(a b) + c`.
