# zip

## What this is
`zip :: [a] -> [b] -> [(a,b)]` — pair up two lists positionally; stop at the shorter.

## Mental model
Produces tuples. Common partner for `zipWith` and list comprehensions over two sources. Stops at the shorter list, no error.

## Syntax
```haskell
zip :: [a] -> [b] -> [(a,b)]
zip []     _      = []
zip _      []     = []
zip (x:xs) (y:ys) = (x,y) : zip xs ys
```

## Small examples
```haskell
>>> zip [1,2,3] "abc"        ==> [(1,'a'),(2,'b'),(3,'c')]
>>> zip [1..] ["a","b","c"]   ==> [(1,"a"),(2,"b"),(3,"c")]
>>> zip3 [1,2] "ab" [True,False]   ==> [(1,'a',True),(2,'b',False)]
```

## Exam use
Adding indices (`zip [0..] xs`), pairing parallel data (e.g. row positions in a matrix).

## Common mistakes
- Silent truncation if lists have different lengths.
- `unzip` is the inverse.
