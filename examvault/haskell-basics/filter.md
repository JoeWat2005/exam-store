# filter

## What this is
`filter :: (a -> Bool) -> [a] -> [a]` — keep elements where the predicate returns `True`.

## Mental model
Drops elements that fail the test. Preserves the order of survivors. Often combined with `map` in a pipeline.

## Syntax
```haskell
filter :: (a -> Bool) -> [a] -> [a]
filter _ []     = []
filter p (x:xs)
  | p x       = x : filter p xs
  | otherwise = filter p xs
```

## Small examples
```haskell
>>> filter even [1..10]               ==> [2,4,6,8,10]
>>> filter (>3) [1,4,2,5,1]          ==> [4,5]
>>> filter (\(_,v) -> v > 0) [("a",1),("b",-1)]   ==> [("a",1)]
```

## Exam use
Common in list-comprehension answers (the guard part). Also in fold-reformulation when the seed wraps `filter` around `map`.

## Common mistakes
- `filter` then `length` — use `foldr` to count without building the intermediate list.
- Negating the predicate by mistake.
