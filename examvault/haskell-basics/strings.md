# strings

## What this is
`String` is just `[Char]`. Every list function works on strings.

## Mental model
Backtick literals (`"abc"`) are sugar for `['a','b','c']`. So `map`, `filter`, `length`, `reverse` all work directly.

## Syntax
```haskell
type String = [Char]

shout :: String -> String
shout = map toUpper
```

## Small examples
```haskell
>>> reverse "hello"           ==> "olleh"
>>> length "hello"            ==> 5
>>> filter isUpper "HeLLo"    ==> "HLL"
```

## Exam use
Caesar cipher and Morse code problems are string-list rewrites. Pretty-printers also live here.

## Common mistakes
- `Char` is single-quoted; `String` double-quoted.
- `show 'a'` returns `"'a'"` not `"a"`.
