# The . operator (composition)

## What this is
`(.) :: (b -> c) -> (a -> b) -> (a -> c)`, `(f . g) x = f (g x)`.

## Mental model
Function composition. Builds a pipeline of functions without naming intermediates. Reads right-to-left.

## Syntax
```haskell
(.) :: (b -> c) -> (a -> b) -> (a -> c)
(f . g) x = f (g x)
```

## Small examples
```haskell
>>> (negate . abs) (-5)            ==> -5
>>> let shout = map toUpper . reverse
>>> shout "hi"                     ==> "IH"
```

## Exam use
Point-free style and pipelines. `length . filter even` counts evens without binding the intermediate list.

## Common mistakes
- Confusing with method `.` from OO languages — Haskell `.` is function composition, not member access.
- Mistakenly using on values: `(+1) . 2` is a type error.
